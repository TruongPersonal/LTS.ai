## <u>11. Recap</u>

### Những gì đã học

1. **aSX** — syntactic sugar cho React.createElement, không phải template, transpile trước khi chạy
2. **Quy tắc aSX** — một root, {} cho expression, camelCase attributes, fragment <>
3. **Function component** — function nhận props, return JSX, có thể tái sử dụng
4. **Props** — object truyền vào component, có thể là kiểu dữ liệu bất kỳ
5. **Children** — special prop cho nội dung giữa thẻ mở/đóng
6. **aSX là expression** — có thể gán biến, return từ function, dùng trong map/ternary

### So sánh với cách cũ

#### Cách cũ Cách React + aSX

Code mô tả các bước (imperative) Code khai báo UI theo dữ liệu (declarative)

Tự quản lý DOM update React tự động re-render Template string / createElement rời rạc Component thống nhất Dễ XSS với innerHTML Auto-escape mặc định

### Khi nào JSX không phải câu trả lời

UI tĩnh, không tương tác → HTML thuần Cần generate UI động từ config → createElement hoặc factory function Dự án không dùng React → JSX là syntax vô dụng

## <u>12. Góc nhìn nâng cao</u>

### JSX không chỉ cho React

JSX là spec riêng (Draft: JSX Specification), không phải của React. Các framework khác cũng dùng JSX hoặc JSX-like syntax:

**Preact** — dùng h() thay vì React.createElement (có thể dùng /** @jsx h */ ) **SolidaS** — JSX nhưng compile thành reactive calls, không cần virtual DOM **Vue** — dùng template (không phải JSX), nhưng cũng support JSX qua plugin

### Component composition vs Inheritance

Bài này học component function cơ bản. Với React, ưu tiên **composition** (ghép component nhỏ thành component lớn) hơn **inheritance** — khác với OOP class truyền thống. Props và children chính là công cụ composition cơ bản.

### Server Components (React 18+)

React 18 giới thiệu **Server Components** — component chạy trên server, không gửi JavaScript xuống client. JSX vẫn là syntax nhưng không transpile thành createElement chạy client — thay vào đó, output là serializable data stream. Đây là chủ đề nâng cao, sẽ học sau.

### Kết luận

JSX + Component model là nền tảng của React. Hiểu JSX là hiểu cách React "nhìn" UI: không phải DOM thao tác thủ công, mà là **cấu trúc dữ liệu** (React element) được xây dựng từ dữ liệu. Từ cấu trúc dữ liệu này, React quyết định DOM cần thay đổi gì. Đây là bước đệm để học useState, useEffect,

và các hooks khác ở bài sau.
