**Track:** ReactJS **Độ khó trong track:** Trung bình **Topic:** React Router v6, BrowserRouter, Route, nested route, dynamic segment, useNavigate, useParams, Link, NavLink, route guards (ProtectedRoute), URL params vs query params **Mục tiêu:** Hiểu React Router hoạt động như thế nào bên dưới — URL change → context update → component re-render. ## 1. Problem Context

#### Neo — Tình huống thực tế

Bạn xây một trang e-commerce. Có các trang: Trang chủ (Home), Danh sách sản phẩm (Products), Chi tiết sản phẩm (Product Detail), Giỏ hàng (Cart), và Trang quản trị (Admin) — mỗi trang một URL khác nhau. Khi click vào sản phẩm, URL chuyển sang /products/123 và trang chi tiết hiện ra. Khi ấn "Giỏ hàng", URL chuyển sang /cart.

#### Manual — Cách suy nghĩ naïve

Dev mới học React thường làm: tạo state page, dùng switch(page) để render component tương ứng:

function App() { const [page, setPage] = useState('home'); return ( <div> <nav> <button onClick={() => setPage('home')}>Home</button> <button onClick={() => setPage('products')}>Products</button> <button onClick={() => setPage('cart')}>Cart</button> </nav> {page ==='home' && <Home />} {page ==='products' && <Products />} {page ==='cart' && <Cart />} </div> ); }

#### Điểm gãy — 5 vấn đề khi app lớn

1. **URL không đồng bộ** — F5 là mất trang, không bookmark được, không share link được.

2. **Không có browser history** — nút Back của trình duyệt không hoạt động.
3. **Không có nested route** — /products/123 cần Products layout chứa ProductDetail, nhưng state page chỉ flat.
4. **Không có dynamic segment** — không biết product id = 123 từ URL, phải tự parse.
5. **Không có route guards** — /admin ai cũng vào được dù chưa login.
#### Cầu nối — Cần một router component

Giải pháp: React Router DOM. Nó đồng bộ URL ↔ component tree, hỗ trợ nested routes, dynamic segments, và navigation API.

## 3. Weakness — Minh họa bằng tình huống thực

### Scenario 1: F5 trên /products/123 → mất trang

Dùng state-driven routing: vào /products/123 → set page='product-detail'. F5 → React app khởi động lại, page='home'. Người dùng thấy trang chủ thay vì sản phẩm. **Không thể bookmark.**

### Scenario 2: Back button không hoạt động

User từ Home → Products → Product Detail. Ấn Back → trình duyệt quay lại trang trước trong history stack (có thể là Google.com), không phải Products page.

### Scenario 3: Nested layout không làm được

Cần layout: Products page có sidebar danh mục + main content area. Khi click sản phẩm, chỉ main content thay đổi, sidebar giữ nguyên. Với state-driven, /products và /products/123 là 2 page riêng biệt → không thể giữ sidebar.

|---|---|---|---|
|F5 mất trang|Load lại → thấy Home|URL không đồng bộ với state — state không persist qua reload|Static (reload)|
|Back không hoạt động|Thoát khỏi app|pushState/popState không được handle đúng|Runtime (click Back)|
|Nested layout impossible|Sidebar biến mất khi vào detail|Flat state không support component tree nesting|Design time|

### The one thing most people get wrong (P13)

**Sai diễn giải phổ biến:** "React Router intercepts HTTP requests và ngăn trình duyệt fetch HTML mới."

**Thực tế:** React Router hoàn toàn chạy phía client. Nó dùng history.pushState() API của browser để thay đổi URL — đây là browser API, không phải network interception. Không có request nào bị chặn hay chuyển hướng. Link prevent default behavior của <a> (vốn gây reload) và thay bằng pushState.

### Framework gotchas (P10)

|Tên|Scenario|Thực tế|Root cause|Nhận biết|Fix|
|---|---|---|---|---|---|
|Index route không path|Tạo route mặc định cho layout|Route không match|Index là route con không có path, match khi URL == parent path|<Route in dex> không path prop|Xoá path|
|useParams() trả về string|So sánh params.i d === product.i (number) d|Luôn false|URL params là string|Dùng === mà kết quả sai|Number(par ams.id)|
|Nested route thiếu /|<Route path="pr vs oducts"> <Rou te path="/produc ts">|Route không match|Relative path vs absolute path trong nested context|Route con không render|Thêm / hoặc bỏ / tuỳ ý định|
|ProtectedRoute flash|Trang admin hiện 0.5s rồi redirect|User thấy nội dung không được phép|ProtectedRoute check async (gọi API check login)|Flash content khi load|Check trước ở root loader hoặc show loading|

## 12. Recap

|Concept|API|Mục đích|
|---|---|---|
|Router|<BrowserRouter>|Cung cấp context routing cho toàn app|
|Route definition|+ <Routes> <Route>|Map URL → component|
|Navigation|<Link>, <NavLink>, useNavigate()|Chuyển trang không reload|
|Dynamic segment|+ path=":id" useParams()|Lấy giá trị từ URL|
|Nested layout|+ <Route> <Outlet>|Layout chia sẻ giữa các page|
|Query params|useSearchParams()|Filter, sort, pagination|
|Route guard|+ <ProtectedRoute> <Outlet>|Kiểm tra quyền trước khi render|
|Location|useLocation()|Đọc URL hiện tại|
|Redirect|<Navigate to="..." replace />|Chuyển hướng có/k replacement|

#### Nguyên tắc:

Dùng Link cho navigation, useNavigate cho logic (sau khi add cart) Dùng :id cho resource identifier,? cho filter Dùng Outlet cho layout chung Dùng ProtectedRoute pattern (không check trong component con) Đặt router ở file riêng nếu > 10 routes

### Data Router (React Router v6.4+)

const router = createBrowserRouter([ { path: "/", element: <RootLayout />, children: [ { index: true, element: <Home />}, { path: "products", element: <ProductsLayout />, children: [ { index: true, element: <ProductList />}, { path: ":id", element: <ProductDetail />, loader: ({ params}) => fetch(`/api/products/${params.id}`), },], },], },]);

#### <RouterProvider router={router} />

loader tự động fetch data trước khi render component → không cần useEffect + useState cho data fetching. Code gọn hơn, loading state được React Router quản lý.

### Lazy loading route — code splitting

import { lazy, Suspense} from'react';

const AdminDashboard = lazy(() => import('./pages/AdminDashboard')); const AdminProductList = lazy(() => import('./pages/AdminProductList'));

<Route path="/admin" element={ <Suspense fallback={<div>Loading...</div>}> <AdminLayout /> </Suspense> }> <Route index element={<AdminDashboard />} /> <Route path="products" element={<AdminProductList />} /> </Route>

Chỉ load code Admin khi user vào /admin — giảm bundle size initial load.

### Scroll restoration

React Router v6 tự động scroll lên đầu trang khi navigate. Nếu cần giữ scroll position, dùng useLocat ion state:

<Link to="/products" state={{ scrollY: window.scrollY}} /> // Dùng ở component đích: location.state?.scrollY
